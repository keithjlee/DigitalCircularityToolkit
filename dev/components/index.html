Component reference

All components are in the DigitalCircularityToolkit tab, grouped by subcategory as in the ribbon. Each entry explains what the component computes and lists its inputs and outputs, as defined in the plugin.

Objects

ComponentDescription
BoxObjectA volumetric box object
LinearObjectA linear object
ObjectA design object
PlanarObjectA planar object
SphericalObjectA spherical object
ObjectPropertiesProperties of a design object
OverridePCAOverride the calculated principal components with a plane whose X,Y components = PCA1, PCA2
DesignObjectDigitalCircularityToolkit design objects

Sets

ComponentDescription
BoxSetA set of box elements
LinearSetA set of linear elements
PlanarSetA set of planar elements
SphereSetA set of spherical elements

Characterization

ComponentDescription
FeatureVectorCreate a feature vector for an object
BoxScoreMeasure how well a box abstracts an input object
LineScoreMeasure how well a line abstracts an input object
PlaneScoreMeasure how well a plane abstracts an input object
SphereScoreMeasure how well a sphere abstracts an input object
HarmonicAnalysisComplexFourier shape descriptor of a complex signature (e.g. ComplexSignature): the radius of each harmonic in model units, independent of sample count, ordered |c1|, |c-1|, |c2|, |c-2|, ... N samples give N-1 values.
HarmonicAnalysisRealFourier shape descriptor of a real-valued signature (e.g. DistanceSignature): the amplitude of harmonics 1, 2, 3, ... in model units, independent of sample count. N samples give N/2 harmonics.
RadialSignaturePerform a radial signature analysis on a curve.

Distance

ComponentDescription
AsymmEuclideanCostCost matrix of asymmetric Euclidean distances: one power when the supply covers the demand, another (or forbidden) when it falls short
EuclideanCostCost matrix of Euclidean distances between demand and supply feature vectors
FrechetDistanceCompute the Frechet distance between two curves
HausdorffDistanceCurveCompute the Hausdorff distance between two curves
HausdorffDistancePointsCompute the Hausdorff distance between two sets of points
ManhattanCostCost matrix of Manhattan distances between demand and supply feature vectors
CostMatrixToTreeCost matrix as a tree of numbers: one branch per demand, one item per supply
CostMatrixCost matrix: rows = demand, columns = supply
AsymmEuclideanDistance(obsolete) Generate a distance matrix of asymmetric Euclidean distances between two feature vector sets (obsolete: integer costs; use AsymmEuclideanCost)
EuclideanDistance(obsolete) Generate a distance matrix of Euclidean distances between two feature vector sets (obsolete: integer costs; use EuclideanCost)
ManhattanDistance(obsolete) Generate a distance matrix of manhattan distances between two feature vector sets (obsolete: integer costs; use ManhattanCost)

Matching

ComponentDescription
AlignToObjectAlign an object to another
AssignAssign supply to demand at the lowest total cost (linear assignment on a cost matrix)
MatchLinesGet the lines that connect supply-demand assignments
Hungarian(obsolete) Hungarian matching algorithm
Match(obsolete) Perform linear assignment of supply to demand using the Jonker-Volgenant algorithm (obsolete: integer costs; use Assign with a CostMatrix)

Utilities

ComponentDescription

NormalizeNormalize a list of numbers by its max value
PairNormalizeNormalize two lists of number by the overall maximum value
PlanarHullGet the planar convex hull of an object
PlanarOutlineGet the planar shadow outline of an object
RotatePCARotate an object about one of its PCAs
