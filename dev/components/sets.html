Sets

Expand design objects by their Quantity into per-instance lists for feature vectors and matching. See Inventories.

BoxSet

A set of box elements

Nickname: BoxSet

BoxSet turns a list of BoxObjects into flat, per-instance lists ready for feature vectors and matching. Each object is repeated Quantity times in a row, so an object with Quantity 3 produces three identical consecutive entries in every expanded output. The number of entries is the sum of all quantities.

Outputs per instance.

  • EffectiveBox: the PCA-aligned bounding box scaled about its center by the buffers (see BoxObject).
  • Plane: the local plane, with X = PCA1 and Y = PCA2, at the center of the box.
  • EffectiveLength, EffectiveWidth, EffectiveHeight: the box extents along PCA1, PCA2 and PCA3, each multiplied by its buffer.
  • Centroids: the center of the PCA-aligned bounding box, not the PCA centroid reported by ObjectProperties.
  • Hulls: the 3D convex hull of each object's sample points, as a mesh.
  • Indexer: for each entry, the index of the source object in the input list. Use it to map a matched instance back to its original object or geometry.
  • IDs: the object ID for each entry.

Objects is not expanded: it returns the input list unchanged.

Workflow. Build one BoxSet for the demand and one for the supply. Feed per-instance dimensions into FeatureVector, compute a cost matrix (for example EuclideanDistance) and solve it with Match. Centroids of both sets go into MatchLines to draw the assignment.

Notes

  • Hulls is computed only when it is connected or the component preview is on; the hulls are then built in parallel. A hull is an empty mesh when an object's samples are collinear or coplanar.
  • Null entries in the input are skipped with the warning "N null object(s) ignored"; Indexer still refers to positions in the original input list.
  • An object with Quantity ≤ 0 contributes no entries.

LinearSet

A set of linear elements

Nickname: LinearSet

LinearSet turns a list of LinearObjects into flat, per-instance lists ready for feature vectors and matching. Each object is repeated Quantity times in a row, so an object with Quantity 3 produces three identical consecutive entries in every expanded output. The number of entries is the sum of all quantities.

Outputs per instance.

  • EffectiveLine, EffectiveLength: the buffered line and its length, LengthBuffer × Length, measured along PCA1 (see LinearObject).
  • Area: the given or estimated cross-section area.
  • CentroidPlane: a plane at the center of the object's PCA-aligned bounding box with X = PCA2 and Y = PCA3, so its Z axis is parallel to PCA1 (the plane of the cross-section).
  • Centroids: the center of the PCA-aligned bounding box (the midpoint of EffectiveLine), not the PCA centroid reported by ObjectProperties.
  • Hulls: the planar convex hull of each object's samples in its local XY plane.
  • Indexer: for each entry, the index of the source object in the input list. Use it to map a matched instance back to its original object or geometry (for example with List Item).
  • IDs: the object ID for each entry.

Objects is not expanded: it returns the input list unchanged.

Workflow. Build one LinearSet for the demand (design members) and one for the supply (inventory). Feed per-instance values such as EffectiveLength and Area into FeatureVector, compute a cost matrix with EuclideanDistance or AsymmEuclideanDistance, and solve it with Match. Centroids of both sets go into MatchLines to draw the assignment.

Notes

  • Null entries in the input are skipped with the warning "N null object(s) ignored"; Indexer still refers to positions in the original input list.
  • An object with Quantity ≤ 0 contributes no entries.

PlanarSet

A set of planar elements

Nickname: PlanarSet

PlanarSet turns a list of PlanarObjects into flat, per-instance lists ready for feature vectors and matching. Each object is repeated Quantity times in a row, so an object with Quantity 3 produces three identical consecutive entries in every expanded output. The number of entries is the sum of all quantities.

Outputs per instance.

  • EffectivePlane: the buffered rectangular surface in the object's local plane (see PlanarObject).
  • Plane: the local plane, with X = PCA1 and Y = PCA2, at the center of the PCA-aligned bounding box.
  • EffectiveLength, EffectiveWidth: LengthBuffer × Length along PCA1 and WidthBuffer × Width along PCA2.
  • Thickness: the given Thickness, or the extent along PCA3 when none was given. No buffer is applied.
  • Centroids: the center of the PCA-aligned bounding box, not the PCA centroid reported by ObjectProperties.
  • Hulls: the planar convex hull of each object's samples in its local plane.
  • Indexer: for each entry, the index of the source object in the input list. Use it to map a matched instance back to its original object or geometry.
  • IDs: the object ID for each entry.

Objects is not expanded: it returns the input list unchanged.

Workflow. Build one PlanarSet for the demand and one for the supply. Feed per-instance values such as EffectiveLength, EffectiveWidth and Thickness into FeatureVector, compute a cost matrix (for example EuclideanDistance) and solve it with Match. Centroids of both sets go into MatchLines to draw the assignment.

Notes

  • Null entries in the input are skipped with the warning "N null object(s) ignored"; Indexer still refers to positions in the original input list.
  • An object with Quantity ≤ 0 contributes no entries.

SphereSet

A set of spherical elements

Nickname: SphereSet

SphereSet turns a list of SphericalObjects into flat, per-instance lists ready for feature vectors and matching. Each object is repeated Quantity times in a row, so an object with Quantity 3 produces three identical consecutive entries in every expanded output. The number of entries is the sum of all quantities.

Outputs per instance.

  • EffectiveSphere, EffectiveRadius: the buffered sphere and its radius, RadiusBuffer × r, where r is the largest distance from the bounding-box center to the sample points (see SphericalObject).
  • Plane: the local plane, with X = PCA1 and Y = PCA2, at the center of the PCA-aligned bounding box.
  • Centroids: the center of the PCA-aligned bounding box, not the PCA centroid reported by ObjectProperties.
  • Hulls: the 3D convex hull of each object's sample points, as a mesh.
  • Indexer: for each entry, the index of the source object in the input list. Use it to map a matched instance back to its original object or geometry.
  • IDs: the object ID for each entry.

Objects is not expanded: it returns the input list unchanged.

Workflow. Build one SphereSet for the demand and one for the supply. Feed EffectiveRadius (and any other per-instance values) into FeatureVector, compute a cost matrix (for example EuclideanDistance) and solve it with Match. Centroids of both sets go into MatchLines to draw the assignment.

Notes

  • Hulls is computed only when it is connected or the component preview is on; the hulls are then built in parallel. A hull is an empty mesh when an object's samples are collinear or coplanar.
  • Null entries in the input are skipped with the warning "N null object(s) ignored"; Indexer still refers to positions in the original input list.
  • An object with Quantity ≤ 0 contributes no entries.
